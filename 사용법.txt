==================================================
 BanG Dream 이벤트 페이지 사용법
==================================================

[1] 이벤트 추가/수정
  - events.csv 파일만 열어서 한 줄 추가/수정하면 끝.

[2] 배포 (사이트에 올리기)
  - Git Bash에서 "[] update_and_push.sh" 실행.
  - 자동으로: index.html 새로 생성 -> 커밋 -> 푸시 -> 사이트 열기 -> 창 닫힘.
  - 성공했을 때만 창이 닫힘. 실패하면 창에 에러가 남음.

  사이트 주소:
  https://bandorigall.github.io/bangdream_events.github.io/


[3] 로컬에서 미리보기 / 디버깅
  - 그냥 index.html 더블클릭해서 봐도 됨 (대부분 잘 보임).
  - 굿즈 계산기 이미지 등이 안 뜨면, 보안 때문이니 작은 서버 띄워서 보기:

      1) Git Bash 또는 터미널에서 이 폴더로 이동
      2) 아래 명령 실행
            python -m http.server 8000
      3) 브라우저에서 접속
            http://localhost:8000
      4) 끌 때는 터미널에서 Ctrl + C

  - 코드(레이아웃/계산기) 고쳤을 때 index.html만 다시 만들고 싶으면:
            python -m make_page
        또는 make_page.bat 더블클릭.


==================================================
 정리
==================================================
  - 이벤트만 추가      -> events.csv 수정 -> "[] update_and_push.sh" 실행
  - 로컬 확인          -> python -m http.server 8000 -> http://localhost:8000
  - index.html만 재생성-> python -m make_page
==================================================
