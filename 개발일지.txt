================================================================
한국오프이벤 — 개발일지
================================================================
(레포: bandorigall/bangdream_events.github.io / GitHub Pages)

■ 배경/동기
  뱅드림 국내 오프라인 이벤트(콜라보 카페, 전시, 내한, 상영회 등)가
  많아지면서, 언제/어디서 열리는지 한 화면에서 캘린더+지도로 보고
  바로 지도앱·예매처로 넘어갈 수 있는 페이지가 필요했다.

■ 구조 확정
  - events.csv 한 곳에서 국내 이벤트 관리(시작·종료·장소·지도링크·좌표·정보·예매).
  - make_page.py 가 CSV를 읽어 index.html 정적 생성. FullCalendar+Leaflet.
  - 좌(카드) / 우(캘린더+상세+지도) 3분할, 카드·캘린더·지도 3자 연동.

■ 주요 결정 및 이유
  - CSV 스키마를 국내/해외 공통으로 통일 → 렌더 코드 100% 재사용.
    해외 CSV엔 네이버/다음지도 열이 없어도 안전하게 동작하도록 map_targets 조립.
  - 지도/좌표/장소를 JSON 배열로 받아 다중 장소(한 이벤트 여러 지점) 지원.
    "검색"이라 적으면 장소명으로 지도 검색 URL 자동 생성.
  - "통합정보모음"과 "예매처"를 "라벨|URL" 포맷으로 → 버튼 이름 커스터마이즈.
  - 지난 행사는 열람 시점 기준으로 자동 숨김(종료일 >= 오늘).
  - cal_end에 종료일+1일: FullCalendar end가 배타적이라 마지막 날이 빠지는 문제 보정.

■ 콜라보 카페 굿즈·메뉴 계산기
  - 콜라보 카페 이벤트에 한해(제목에 '콜라보 카페') 장바구니 모달 노출.
  - 특전 자동 계산: 메뉴당 코스터 1장, 4만원당 엽서·8만원당 포스터,
    돌로리스 생일 엽서(2026-06-26~07-02 한정)까지 규정 그대로 코드화.
  - 굿즈/메뉴/특전 이미지는 assets/cafe/(thumb·source)로 관리, 썸네일 클릭 라이트박스.

■ 해외 탭(베타)
  - 해외오프이벤/scraper.py: bang-dream.com events/news를 stdlib만으로 스크랩.
  - 장소명 → OSM Nominatim 지오코딩(venues.json 캐시), 공지 → Gemini 한국어
    요약(summaries.json 캐시). Gemini 키는 gitignore로 커밋 차단.
  - 네트워크 실패 시 기존 CSV를 덮어쓰지 않음(안전). manual_overseas.csv로 수동 보정.
  - (관련: 상위 memory "해외 오프이벤 스크래퍼" 참조)

■ 운영 메모
  - 국내 이벤트: events.csv 한 줄 → "[] update_and_push.sh".

  - 로컬에서 이미지 안 뜨면 python -m http.server 8000 로 확인(file:// 보안 제한).
